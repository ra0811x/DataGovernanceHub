映射管理使用参考

核心功能

映射管理用于定义导出时每一列如何取值。数据可以来自数据概览表、合并结果表、公共配置，或由条件判断、动态生成、多行展开等逻辑计算得到。页面中的修改只有在点击“保存配置”提交到服务器后，才视为正式生效。

1. 当前页面如何操作

  1. 选择报表：先在左侧选择分类和具体报表。
  2. 查看映射：右侧会显示当前报表所有列的映射配置。
  3. 选择类型：先选操作类型，再选数据源类型。
  4. 简单类型：固定值、字段索引这类映射，可直接在表格里填写或下拉选择。
  5. 复杂类型：条件判断、跨表查询、动态生成、多行展开这类映射，需要点击右侧配置入口或弹窗完成详细设置。
  6. 保存生效：点击底部“保存配置”按钮提交到服务器，保存后才视为正式生效。
  7. 建议验证：保存后先做测试导出，再执行正式导出。

2. 常见数据源类型 (source_type)

sequence - 序号
自动生成递增序号
source_type: "sequence"
fixed - 固定值
填写固定的文本或数字
source_type: "fixed"
source_value: "湖北移动"
field_index_merge_results
从合并结果表按数据库真实索引获取字段
source_type: "field_index_merge_results"
source_value: "4"
field_index_assets
从数据概览表按索引获取字段
source_type: "field_index_assets"
source_value: "13"
conditional - 条件映射
根据条件判断返回不同的值
source_type: "conditional"
lookup_ip - IP查询
通过IP从数据概览表查询信息
source_type: "lookup_ip"
vlookup_assets - 跨表查询
使用某个字段值到数据概览表联查，再返回目标字段
source_type: "vlookup_assets"
vlookup_assets_with_mapping
先经过公共配置映射，再到数据概览表联查
source_type: "vlookup_assets_with_mapping"
field_assets_dynamic
基于字段值、参考列和上下文生成动态文本
source_type: "field_assets_dynamic"
field_assets_with_transform
先读取字段，再按规则或 transform 输出结果
source_type: "field_assets_with_transform"
multi_strategy_config
把一条源记录展开成多条策略记录
source_type: "multi_strategy_config"
strategy_content_mapping
根据展开后的策略类型返回对应内容
source_type: "strategy_content_mapping"
并不是所有报表都会同时使用上述全部类型。以当前报表字段、右侧配置入口和保存后的导出效果为准。

3. 转换规则 (transform)

转换规则 说明 示例
split_before_slash 取 "/" 前的部分 "db_name/schema" → "db_name"
remove_ip_brackets 去除 [IP] 格式 "表名[192.168.1.1]" → "表名"
（留空） 不进行转换 原样输出
普通字段提取型映射可以直接配合 transform 使用；“字段+转换”“动态生成”“多行展开”等复杂类型主要通过右侧配置面板维护，不只依赖 transform 字段。

4. 字段索引说明

重要提示

字段索引起始于 0，而不是 1。

其中 merge_results 与 assets 均采用当前系统实际列配置口径，id 为索引 0。

优先使用页面当前下拉框选择字段，不建议手工猜索引。

如果导入结构、列配置或模板发生变化，请以页面当前可选字段和实际配置为准，不要只依赖示例文字手填索引。

5. 实际使用示例

示例1：固定值
{
  "target_column": "B",
  "target_name": "所属部门",
  "source_type": "fixed",
  "source_value": "数智化部",
  "transform": "",
  "description": "固定值"
}
示例2：从合并结果表获取字段（按真实数据库索引）
{
  "target_column": "K",
  "target_name": "数据名称",
  "source_type": "field_index_merge_results",
  "source_value": "8",
  "transform": "",
  "description": "数据类型"
}

6. 使用建议

  1. 简单字段：优先用字段索引下拉选择，不要手工猜索引。
  2. 复杂规则：优先通过右侧配置入口维护，不要只改表格中的简写值。
  3. 保存后测试：建议先保存，再做测试导出确认结果。
  4. 旧配置兼容：如果看到历史命名或旧类型，以当前页面回显和右侧配置面板为准。

7. 公共配置说明

公共配置 (business_system_name_mapping)

用于将合并结果表中的业务系统名称映射到数据概览表中的标准名称，确保跨表查询时能够正确匹配。

映射示例：
合并结果表名称 → 数据概览表名称
湖北移动业支运营支撑系统 → BOSS系统
OA业务支撑 → OA系统
掌微厅系统 → 掌微厅系统
如何使用公共配置

1. 在映射管理页面点击左侧 "公共配置" 按钮

2. 选择 "business_system_name_mapping" 这一项公共配置查看或编辑映射关系

3. 在配置中使用 vlookup_assets_with_mapping 数据源类型时，会自动应用此映射字典

数据处理使用参考

工作台说明

数据处理页把一键处理、数据拆分、CSV 转换和数据去重集中在同一工作台中。你可以在同一页面里切换模式、查看左侧实时状态、预览待处理文件，并在处理完成后直接下载结果或导出日志。

1. 四种处理模式

一键处理
输入压缩包目录，系统会批量扫描 ZIP，清洗其中的 Excel，并自动输出合并结果表。需要设置目标列索引，当前默认值是 H 列 = 7。
数据拆分
输入 Excel 文件目录，先预览文件列表，再按拆分数量和标题行规则输出多份文件。拆分数量至少为 2，输出文件名前缀可选。
CSV 转换
输入 Excel 文件目录，先预览并勾选待处理文件，再批量转换为 CSV，适合给数据库导入或其他系统继续处理。
数据去重
输入 Excel 文件目录，先预览并勾选待处理文件，再生成去重结果压缩包。输出压缩包名称可选，留空时使用默认名称。

2. 通用操作流程

  1. 切换模式：先选择一键处理、数据拆分、CSV 转换或数据去重。
  2. 输入目录：按当前模式填写正确目录。一键处理使用压缩包目录，其他三种模式使用 Excel 文件目录。
  3. 预览文件：建议先点击“预览文件列表”，确认系统识别到的文件数量和大小。
  4. 选择文件：拆分、CSV、去重三种模式支持勾选文件，可用“全选/全不选”快速调整范围。
  5. 开始处理：点击主按钮发起任务，左侧实时状态区会持续展示当前进度。
  6. 查看结果：处理完成后，在结果区查看统计信息并下载输出文件。
  7. 导出日志：如需留痕或排查问题，可导出当前模式日志。

3. 关键差异和注意事项

一键处理使用压缩包目录，其他三种模式使用 Excel 文件目录。这是当前页面最容易填错的一项。
修改目录输入框后，当前模式已预览的文件选择会被清空，需要重新预览并确认。
数据拆分要求“拆分数量至少为 2”，标题行按原文件头部保留；CSV 转换和数据去重不需要设置标题行。
目录路径会保存在本地浏览器缓存中，点击对应“清空”按钮会清除当前输入，并清空这一模式下的已预览选择状态。

4. 结果与日志说明

处理完成后，可在结果区直接查看成功状态、文件数量、行数或去重统计，并下载对应结果文件。日志导出按当前处理模式生成，适合保留过程记录、回溯失败原因或给后端排查问题时使用。
